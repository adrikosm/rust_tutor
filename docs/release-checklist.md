# Beta release checklist

- [x] GK0/WK/KF source and provenance foundations are frozen and validated.
- [x] GF2 typed tutor feed validates at runtime.
- [x] Gates 0–8 evidence: governance, contracts, local app, event store, evaluator, learning loop, graph/search, curriculum/projects, and exact exam contract.
- [x] macOS/Linux matrix, local-only production origin, CSP/offline assets, backup/restore and hostile-request/import tests.
- [x] Fresh source-copy install/build/test and native macOS package offline smoke test; no Docker/OCI release artifact is required.
- [x] MIT repository license, source/license ledger, SBOM, contributor/security/conduct docs, changelog, migration/rollback notes.
- [ ] Public beta publication is a separate external action; this repository does not call the full course complete.
- [ ] Full-core/full-parity publication remains gated on G10/G11 manifests and reviewed stage evaluator evidence.
