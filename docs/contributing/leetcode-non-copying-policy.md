# LeetCode non-copying policy

Do not copy LeetCode prompts, examples, constraints, tests, editorial text, solution structure, images, or paid/community content into this repository. A public URL may be kept as private study metadata when its use decision permits link-only study.

Every local algorithm item must have an independently authored scenario, wording, fixtures, expected behavior, rubric, and hidden tests. Similarity at the underlying algorithm-pattern level is allowed; expression and test assets must be original or separately licensed.

Use [the local problem template](problem-template.md). Missing originality or license fields block release.
