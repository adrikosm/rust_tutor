# Content license decision checklist

Before content promotion, record the source snapshot ID/hash and classify each relevant file class independently: code, prose, tests, and assets.

- **Original:** authored for this repository; retain authorship and review evidence.
- **Permissive:** exact license permits intended redistribution/modification; preserve notices and scope.
- **Link-only:** metadata and link may be stored, but source content is not republished.
- **Prohibited:** license, terms, provenance, or ownership is incompatible or unresolved; block promotion.

The reviewer must also record scope, upstream version/date, intended use, attribution/notice obligations, copied-byte boundaries, and whether hidden tests or solutions would be exposed. “Available online” is not a license.
