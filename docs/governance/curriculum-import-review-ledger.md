- Before this gate the 109 Book pages carried only a `sourceDocumentId`; the typed blocks in `rust-book.json` were never loaded by the service or rendered by the web app, so the Book track had no readable content. Each lesson now embeds its public `sourceDocument` projection (provenance, headings, typed blocks) through the single `mappedBookFields` funnel, matching how Mainmatter exercises already carry theirs, so one release checksum still covers everything rendered. Release size 5.2 MB → 8.3 MB.
- `schemas/curriculum.v2.schema.json` gained a `bookSourceDocument` definition; the lesson `sourceDocument` property previously `$ref`ed the Mainmatter shape, which no Book page could satisfy.

### Server-graded recall checks

- `POST /api/v1/lessons/{id}/checks/{checkId}` grades server-side and commits idempotently; `GET /api/v1/lessons/{id}/checks` restores commitments after a reload. The answer key and explanation never leave the service before commitment, and `explanation` was removed from the client lesson schema so nothing can read it early.
- Commitments reuse the existing append-only `quiz_attempt_event` table rather than a new one, so export, import, reset, and recovery cover Book progress with no new plumbing.
- The first answer is final: a later different answer returns the original commitment rather than overwriting it. Verified live (commit → resubmit returns first answer; out-of-range rejected 422) and by integration test.
